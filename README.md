# Розумна галерея

PWA для фото, відео, посилань, нотаток, голосових і PDF — розкладених по темах-альбомах, з сердечками й тегами.
Дані зберігаються в браузері (IndexedDB) і працюють без інтернету. За бажанням — спільна галерея через Supabase
([налаштування](supabase/README.md)): усі учасники бачать і сортують ті самі фото.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (і в локальній мережі — для телефону)
npm run build      # збірка в dist/
npm run preview    # перевірити збірку (з офлайн-кешем)
npm test           # перевірка резервної копії та синхронізації (два «телефони» з імітацією сервера)
npm run icons      # перегенерувати PNG-іконки
```

Щоб встановити на телефон як застосунок, потрібен HTTPS (або localhost): викладіть `dist/` на будь-який
статичний хостинг (GitHub Pages, Netlify, Cloudflare Pages). Шляхи відносні, маршрути через `#`.

Публікація на GitHub Pages автоматична: `.github/workflows/deploy.yml` збирає й викладає застосунок після кожного
push у `main`. Один раз треба увімкнути: Settings → Pages → Source: **GitHub Actions**.

## Що вміє

- **Галерея** — сітка за датами («Сьогодні», «Вчора», «Жовтень 2026»), 3/5/7 у ряд (щипок, Ctrl+коліщатко або кнопка),
  тривалість на відео, сердечко на улюблених. У налаштуваннях можна показувати всі типи, а не лише фото й відео.
- **Теми** — назва, емодзі, колір, обкладинка (авто / вибрати з теми / завантажити), підтеми, перейменування,
  видалення (елементи лишаються), зміна порядку перетягуванням. Елемент може бути в кількох темах. «Без теми» — окремий список.
- **Кольорові сердечка** — шість кольорів-категорій зі спільними назвами («Картки магазинів», «QR-коди», «Документи»…).
  Вкладка «Сердечка» з фільтром за кольором, який запам'ятовується, і ярлик на головному екрані. **Теги** `#важливо` для пошуку.
- **Спільна галерея** — створити або приєднатися за кодом-запрошенням, учасники, «хто додав». Зміни приходять одразу,
  без інтернету все складається в чергу; оригінали з сердечками зберігаються на телефоні.
- **Лише на цьому телефоні** — позначка для окремих фото (наприклад, документів): вони не надсилаються в спільну галерею,
  а якщо вже були там — прибираються із сервера й у інших учасників.
- **Додавання** — «+» → фото / відео / імпорт багатьох / посилання (превʼю) / текст / голосове (запис із мікрофона або файл) / файл.
  Підпис, примітка, теми, теги, сердечко. Дата фото береться з EXIF.
- **Перегляд** — свайп вліво/вправо, свайп вниз — закрити, подвійний тап і щипок — зум, свій відеоплеєр
  (перемотка ±10 с, швидкість 0,5×–2×), «Інфо» з редагуванням підпису, примітки, тем і тегів.
- **Масові дії** — утримання (або правий клік) → вибір → улюблене, у тему, перемістити, поділитися, видалити.
- **Редактор фото** — обрізка (вільно / пропорції), поворот, яскравість, контраст, «Відмінити». Оригінал не змінюється,
  кнопка «Оригінал» повертає його.
- **Пошук** — підписи, примітки, тексти, теги, назви тем; фільтри за типом, темою, улюбленим, датами; сортування.
- **Кошик** — 30 днів, потім автоочищення; відновлення або видалення назавжди.
- **Резервна копія** — ZIP з усіма файлами й `backup.json`; імпорт «додати до наявного» або «замінити все».
- Світла / темна / системна тема, українська мова, офлайн-робота.

## Структура

- `src/lib/db.js` — єдиний доступ до IndexedDB (сховища `items`, `themes`, `files`).
- `src/lib/store.js` — стан у пам'яті + усі зміни даних. `selectors.js` — пошук, сортування, групування.
- `src/lib/media.js` — мініатюри, метадані відео/аудіо, EXIF, рендер редагувань.
- `src/lib/backup.js` — власний ZIP без стиснення (файли не копіюються в пам'ять).
- `src/lib/cloud/` — спільна галерея: `sync.js` (outbox → Supabase, отримання змін, докачування файлів), `config.js` (адреса й ключ проєкту).
- `supabase/schema.sql` — таблиці, правила доступу, функції.
- `src/lib/nav.js` — маршрути через hash і закриття оверлеїв кнопкою «Назад».
- `src/components/` — сітка, перегляд, редактор, шторки; `src/screens/` — екрани.
- `public/sw.js` — офлайн-кеш. Після змін у `sw.js` збільшити `VERSION`.

## Обмеження

- Превʼю посилань отримується через публічний сервіс microlink.io (адреса посилання передається йому). Вимикається в налаштуваннях;
  для YouTube картинка є і без нього.
- Браузер може очистити сховище, якщо мало місця. Кнопка «Захистити» в налаштуваннях просить постійне сховище;
  найнадійніше — встановити застосунок і робити резервні копії.
- Архів резервної копії — до 4 ГБ (формат ZIP без ZIP64).
- HEIC-фото показуються лише там, де браузер їх підтримує (Safari); інакше їх можна зберегти файлом.
