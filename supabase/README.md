# Спільна галерея: налаштування Supabase

Один раз, приблизно 5–10 хвилин. Безкоштовного тарифу вистачає: 500 МБ бази й 1 ГБ файлів.

1. **Проєкт.** Зайдіть на [supabase.com](https://supabase.com) → *Start your project* (можна увійти через GitHub).
   *New project*: назва будь-яка (наприклад `galereya`), пароль бази — згенеруйте й збережіть,
   регіон — *Central EU (Frankfurt)*. Зачекайте 1–2 хвилини, поки проєкт створиться.
2. **Таблиці.** Ліворуч *SQL Editor* → *New query* → вставте весь вміст файлу [`schema.sql`](schema.sql) → *Run*.
   Має з'явитися *Success. No rows returned*.
3. **Анонімний вхід.** *Authentication* → *Sign In / Providers* → увімкніть
   **Allow anonymous sign-ins** → *Save changes*. Учасникам не потрібні пошта чи пароль —
   вони приєднуються за кодом запрошення.
4. **Ключі.** *Project Settings* → *API Keys* (або кнопка *Connect* угорі). Скопіюйте:
   - **Project URL** — `https://xxxx.supabase.co`;
   - **publishable key** (`sb_publishable_…`) або **anon public** key.

   Ці два значення публічні: вони вбудовуються в сайт, а дані захищають правила доступу з `schema.sql`.
   **Secret key / service_role не передавайте нікому** — він обходить усі правила.

Значення з кроку 4 вписуються у [`src/lib/cloud/config.js`](../src/lib/cloud/config.js).

## Як це працює

- У проєкті одна галерея. Її створює перший, хто натисне «Створити спільну галерею» в налаштуваннях.
  Решта приєднується за посиланням-запрошенням або кодом.
- Кожен учасник бачить усе, може додавати, ставити сердечка, видаляти.
- Фото зберігаються і на телефоні, тож сердечка відкриваються без інтернету.
- «Новий код» вимикає старе запрошення; учасника можна прибрати зі списку.
- Обмеження безкоштовного тарифу: файл до 50 МБ (довші відео лишаються лише на телефоні, де їх додали).
